# سامانه جامع سلامت روان سامان (Saman Mental Health Platform)

سامان یک پلتفرم پیشرفته و امن در حوزه سلامت روان است که بر اساس استانداردهای مهندسی نرم‌افزار مدرن، معماری کلینیکال و اصول طراحی سیستم‌های توزیع‌شده آفلاین-اول (Offline-First) پیاده‌سازی شده است. این سامانه به طور همزمان به نیازمندی‌های درمانگران، مراجعان (بیماران) و کادر پذیرش کلینیک پاسخ می‌دهد.

---

## 🎯 اهداف پروژه

1. **مدیریت جامع بالینی:** ثبت و پیگیری پرونده بیماران، رزرو نوبت‌دهی و نگهداری یادداشت‌های بالینی SOAP با بالاترین استانداردهای امنیتی.
2. **رمزنگاری اطلاعات در سطح استراحت (Encryption at Rest):** محافظت کامل از داده‌های حساس بیماران با استفاده از الگوریتم **AES-256-GCM** در پایگاه داده SQLite بر روی دیسک.
3. **معماری آفلاین-اول و همگام‌سازی (Offline-First & Outbox Pattern):** امکان کارکرد مداوم در شرایط قطعی اینترنت و همگام‌سازی خودکار تغییرات پس از اتصال مجدد.
4. **دستیار هوشمند هوش مصنوعی:** ادغام امن با مدل‌های پیشرفته گوگل (Gemini AI Gateway) جهت تحلیل حالات روحی، خلاصه‌سازی پرونده و چت درمانی با رعایت حریم خصوصی.
5. **کنترل دسترسی دقیق و ممیزی (RBAC & Audit Logging):** ثبت تمامی دسترسی‌ها و تغییرات بالینی در سیستم ممیزی غیرقابل انکاری (Audit Log).

---

## 🏗️ معماری پروژه (Modular Monolith + Micro-Kernel)

پروژه بر پایه معماری **Modular Monolith** با لایه‌بندی دقیق (Clean Architecture) توسعه یافته است:

* **Shell / UI:** کامپوننت‌های واکنش‌گرا با React و Tailwind CSS.
* **Application / Use Cases:** سرویس‌ها و هندلرهای بیزینس لاژیک.
* **Domain:** موجودیت‌ها (Entities)، اشیاء مقداری (Value Objects) و رویدادهای دامنه.
* **Contracts:** اینترفیس‌ها و قراردادهای مخازن (Repositories) و سرویس‌ها.
* **Infrastructure:** پیاده‌سازی‌های واقعی (مخازن SQLite، موتور Outbox، کلاینت AI و REST API).
* **Server AI Gateway:** تمام درخواست‌های هوش مصنوعی از طریق سرور پروکسی می‌شوند و هیچ‌گاه کلید API یا SDK در سمت کلاینت لور نمی‌رود.

---

## 📁 ساختار پوشه‌های پروژه (`src/`)

```text
src/
├── core/               # میکروکرنل (مدیریت پلاگین‌ها، EventBus و Slot Manager)
├── domain/             # موجودیت‌های دامنه، رویدادها و قوانین بیزینس
├── contracts/          # اینترفیس‌های مخازن، AI Gateway و Sync Engine
├── infrastructure/     # پیاده‌سازی‌های زیرساختی (IndexedDB، Outbox، SQLite)
├── application/        # Use Cases و سرویس‌های کاربردی
├── plugins/            # پلاگین‌های ایزوله (درمانگر، مراجع، پذیرش)
├── components/         # کامپوننت‌های رابط کاربری و رندرهای اسلات
└── server/             # ماژول‌های بک‌اند NestJS (Auth، AI، Sync، Audit، SQLite)
```

## 🔌 سیستم پلاگین‌ها (4-Level Plugin Architecture)

سیستم پلاگین‌های سامانه سامان به صورت ۴ سطحی طراحی شده است:
1. **Manifest:** توصیف‌گر قابلیت‌ها و متاادیتای پلاگین.
2. **Capabilities:** تعیین دسترسی‌ها و سطوح مجاز.
3. **Backend Contract:** قراردادهای ارتباطی با سرور ماژولار.
4. **Frontend Module/Slot & Events:** تزریق پویای کامپوننت‌ها به محیط کاربری از طریق Slot Manager.

*نکته امنیتی:* پلاگین‌ها به هیچ عنوان به صورت مستقیم به پایگاه داده دسترسی ندارند و تمامی عملیات خود را از طریق Domain Services و Repository Contracts انجام می‌دهند.

## ✅ کارهای انجام شده و دستاوردها

1. **رمزنگاری AES-256-GCM پایگاه داده:** پیاده‌سازی کامل رمزنگاری فایل SQLite روی دیسک همراه با تأیید صحت Tag احراز هویت.
2. **سرویس AI Gateway:** پروکسی امن سمت سرور برای ارتباط با مدل‌های Gemini و سیستم Fallback خودکار.
3. **موتور Outbox و همگام‌سازی آفلاین:** مدیریت صف تراکنش‌های آفلاین برای بیماران، یادداشت‌های بالینی، لاگ‌های خلق و نوبت‌ها.
4. **سیستم جامع تست و پایداری:** پوشش کامل تست‌های خودکار شامل:
   * تست‌های رمزنگاری دیتابیس (`database-encryption.test.ts`)
   * تست‌های برش عمودی و راه‌اندازی مجدد سرور (`e2e-vertical-slice.test.ts`)
   * تست‌های یکپارچه‌سازی ماژولار (`integration.test.ts`)
   * تست‌های کنترل دسترسی و مدیریت پنل‌ها (`panel-visibility.test.ts`)
5. **پاک‌سازی معماری و امنیت احراز هویت:** حذف حساب‌های درفت اضافی، یکپارچه‌سازی نقش درمانگر و مدیریت دسترسی‌های پنل پذیرش (`reception`).

## 🚀 راه‌اندازی و اجرای پروژه

### پیش‌نیازها
* Node.js (نسخه ۱۸ به بالا)
* NPM

### نصب وابستگی‌ها
```bash
npm install
```

### اجرای محیط توسعه (Development)
```bash
npm run dev
```

### اجرای تست‌های جامع
```bash
npx tsx tests/integration.test.ts
npx tsx tests/e2e-vertical-slice.test.ts
npx tsx tests/database-encryption.test.ts
npx tsx tests/panel-visibility.test.ts
```

### بیلد برای محیط تولید (Production Build)
```bash
npm run build
```
